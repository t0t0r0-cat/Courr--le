## the reason why you should program dynamicly unlike this repo...
You change one thing in the source css files or html layout and you wonder why the output file isnt changing, because you didnt change the generator code. 💀
## If you really want to use it, here's how to set it up
### prerequisites:
- python, preferably 3.10 or newer, but it _*should*_ work with older versions too...
- ``BeautifulSoup`` library
### setup and running:
clone the git repo ``git clone github.com/t0t0r0-cat/Courr--le``
go to the project dir, usually here ``cd Courr--le``
run ``generate.py`` with ``python generate.py`` duh!
